Keep persistent Chromium sessions on your Mac and access them from MCP, the
CLI, a local API, or the typed Rust client.

## Start with one command

The bundled `rel` CLI is the quickest way to capture a rendered page and the best place to learn REL’s model.

```sh
rel https://rel.me
```

REL keeps Chromium inside the installed macOS app. Like curl, the CLI writes
page data to standard output and events to standard error, so either stream can
be piped or redirected independently.

[Read the CLI guide →](/cli/)

## Supported runtime

REL has one supported path: the installed `/Applications/Rel.app` owns Chromium and supervises its bundled local agent. CLI, SDK, and MCP adapter calls connect to that agent; the agent routes browser work back into the visible app.
